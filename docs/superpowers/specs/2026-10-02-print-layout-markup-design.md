# 打印工单版式标注修正设计

**日期：** 2026-10-02  
**状态：** 已批准并已实现  
**来源：** 打印样张手写标注 + 口径澄清

## 目标

按打印样张标注，收紧固定标签格、加宽关键数据区，并修正装订单位与成品规格换行问题，使预览/打印更接近实际纸质工单。

## 范围

- **只改预览/打印：** `src/renderer/src/lib/workOrderDoc.js`、`src/renderer/src/styles/base.css`
- **不改：** `EditForm.vue`、字段模型、`cks` 逻辑、侧栏/编辑一屏布局

## 修改清单

| # | 位置 | 改法 |
|---|------|------|
| 1 | 全部固定文案标签格（`.label` / `.narrow-label` / `.pack-label`） | 去左右内边距（约 `0 1px`），按文案收窄列宽 |
| 2 | 「合同号」列 | 加宽（宽度来自左侧标签收窄） |
| 3 | 「备注」区（`.remark-cell`） | 减小上内边距，内容略上移 |
| 4 | 开纸尺寸数字（`.size-merge` 内 1.19 / 0.89 等） | 字号加大 |
| 5 | 装订数量格 | 删除多余「个」；格内固定显示单位「张 / 本 / 份」，无编辑态单位控件 |
| 6 | 成品规格「横 / 竖」 | 强制同一行不换行：`横 … cm　竖 … cm` |
| 7 | 「成品规格 / 四边留位」整块 | 横向加宽 |
| 8 | 「合格证」列 | 缩短 |
| 9 | 「有厂名」列 | 缩短约一半 |
| 10 | 包装区整体 | 列宽重分配后自然左收；不做额外绝对定位 |

## 实现策略

### CSS 统一收紧标签格

- 在 `base.css` 统一收紧 `.form-doc .label`、`.narrow-label`、`.pack-label` 的水平 padding
- 不全局清零所有 `td` padding，避免数据格（客户名、产品名、备注等）变挤

### 列宽重分配（`workOrderDoc.js` 内联 width / colgroup）

- 订印单位行：标签列收窄 → 合同号列加宽；客户内容列可略让宽给合同号
- 成品规格表：成品规格+四边留位区域加宽；合格证、有厂名（及同列包装选项）收窄
- 包装「位置」靠列宽调整达成，不引入绝对定位或负 margin

### 装订单位

当前模板存在：

```html
<span class="zd-val">…</span>个<span class="zd-unit">张</span>
```

改为只保留固定单位，例如：

```html
<span class="zd-val">…</span><span class="zd-unit">张</span>
```

「本」「份」格保持同样模式（数值 + 固定单位）。

### 成品规格单行

- `.spec-wrap` / `.spec-group` 保持 `white-space: nowrap`
- 必要时略减内部 gap / padding，避免两段在窄列下折行

### 开纸数字字号

- 提高 `.size-merge`（及必要时其内数字）的 `font-size`，勾选框尺寸可略跟调以对齐

## 非目标

- 不改编辑态布局与控件
- 不新增字段、不改数据读写
- 不做像素级“完全贴合手写箭头”的绝对定位微调

## 验收

1. 预览打印：标签格更紧，合同号、成品规格区更宽；合格证/有厂名更窄
2. 装订数量格只出现一个固定单位字（张/本/份），无多余「个」
3. 成品规格「横」「竖」同排单行显示
4. 开纸区 1.19 / 0.89 等数字明显大于改前
5. 备注内容相对改前略靠上
6. 编辑态与字段保存行为不变
